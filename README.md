## Project Description
Console-based JavaScript fundamentals: variables, data types, functions, control flow, arrays, objects, JSON, calculator and grade tracker projects. Built with my personal data (20 years, Kenya, birthYear 2006).

## Technologies Used
- JavaScript (ES6+)
- HTML5
- CSS3

## Features
- Interactive calculator with all operators
- Grade tracker system (averages, top student, report cards)
- Array methods: map, filter, reduce, find, sort
- Daily Challenges: FizzBuzz, reverse string, largest number, remove duplicates, palindrome

## How to Run
1. Clone: `git clone https://github.com/preciousndegwa48/week-4-javascript-basics.git`
2. Open `index.html` in browser and check console (F12)
   OR run `node main.js`

## Lessons Learned
Learned typeof, template literals, function types, array methods, objects, JSON parse/stringify, try/catch.
